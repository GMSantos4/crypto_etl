# crypto_etl

A simple data engineering project from CoinGecko API to streamlit.

# Architecture (core business)

The project has the following structure:

```text
CRYPTO_ETL
├── app/
│   ├── __init__.py
│   ├── dashboard.py
│   ├── extract.py
│   ├── load.py
│   ├── main.py
│   └── transform.py
├── assets/
├── data/
│   └── crypto_db.db
├── compose.yaml
├── Dockerfile
├── README.md
└── requirements.txt
````
